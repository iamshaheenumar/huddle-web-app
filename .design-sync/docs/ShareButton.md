# ShareButton

40×40 white icon button (`rounded-[13px]`, `1px solid #EAE5DD` border) with a share glyph. Opens the native share sheet for the current page; where unavailable it copies the URL and flips to an ink (`#20242E`) button with a check mark for 1.6s. Used in the History header next to the title.

```tsx
<ShareButton groupName="Home" />
```
