# MembersSectionSkeleton

Loading placeholder for the dashboard Members section: a heading row plus four equal-width member cards (avatar + two text lines). Takes no props. Built from `Sk`. Designed for the 430px-wide mobile column; it carries its own horizontal margins/padding (`px-5`/`mx-5`), so place it directly in the page column.

```tsx
<MembersSectionSkeleton />
```
