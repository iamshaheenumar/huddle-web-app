# CategoriesSectionSkeleton

Loading placeholder for the dashboard Categories section: a heading row plus a white card with four category rows (icon, label, amount, progress bar). Takes no props. Built from `Sk`. Designed for the 430px-wide mobile column; it carries its own horizontal margins/padding (`px-5`/`mx-5`), so place it directly in the page column.

```tsx
<CategoriesSectionSkeleton />
```
