# BudgetHeroCardSkeleton

Loading placeholder for the dashboard's blue budget hero card (gradient `#4D79F8 → #3461E8`, `rounded-3xl`, `mx-5`). Takes no props. Built from `Sk`. Designed for the 430px-wide mobile column; it carries its own horizontal margins/padding (`px-5`/`mx-5`), so place it directly in the page column.

```tsx
<BudgetHeroCardSkeleton />
```
