# RecentActivitySectionSkeleton

Loading placeholder for the dashboard Recent activity section: a heading plus four white activity rows (avatar, two text lines, amount). Takes no props. Built from `Sk`. Designed for the 430px-wide mobile column; it carries its own horizontal margins/padding (`px-5`/`mx-5`), so place it directly in the page column.

```tsx
<RecentActivitySectionSkeleton />
```
